# 英语语感训练器

从「中文思维」到「英文输出」的语感训练工具。不是翻译器——围绕句式拆解、产出训练和记忆沉淀设计。

## 功能模块
1. **AI 跟写** — 写中文，英文流式跟译（增量翻译，只译新内容，完整句自动句式解剖）
2. **句式解剖** — 整句按语法成分着色标注（主谓宾定状从），上方标中文对照，详细拆解折叠
3. **先写后看** — 先自己写英文，逐块批改，错误归因到中式思维习惯
4. **渐进挖空** — 填空 → 骨架首字母 → 裸句默写，逐层撤拐杖
5. **回译循环** — 英→中→英，暴露"自以为会了"的薄弱点
6. **弱点画像** — 错误按思维习惯归类统计，定向生成陷阱练习
7. **场景造句** — 给场景选句式骨架自由造句
8. **句式库 + 间隔复习** — 按句式归类沉淀，SM 简化版间隔调度

## 账号系统
注册/登录后数据按账号存储在服务端（`data/<user>.json`），跨设备不丢。API Key 只存在服务端，浏览器接触不到。

## 部署
```bash
cp .env.example .env   # 填入 LLM_API_KEY 等
node server.js         # 默认 8787
```
支持两种 LLM 端点（自动识别）：
- OpenAI 兼容：`LLM_BASE_URL=https://open.bigmodel.cn/api/paas/v4`
- Anthropic 兼容（GLM 编码套餐）：`LLM_BASE_URL=https://open.bigmodel.cn/api/anthropic`
